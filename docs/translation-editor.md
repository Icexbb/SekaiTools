# 翻译编辑工作流

## 载入与替换

先载入 JSON / asset 剧本，再载入 TXT 翻译。翻译文件成为当前编辑内容；参考翻译仅供对照。

载入后按钮变为“更换”，始终用于选择文件。“清除…”菜单分别提供清除当前译文、移除参考、清除整个工作区。替换和清除当前编辑内容时仍有未保存保护。导入失败时保留当前内容，页面显示可复制的详细原因。

## 状态与定位

- “恢复草稿已更新”表示本地恢复副本已写入，不等于翻译文件已保存。
- “未译”正文导出时沿用原文；“有意留空”正文在 TXT v2 中导出为空白；“沿用原文”是显式使用原文的条目。
- 条目操作支持切换上述状态、采用参考正文和查看上下文，正文操作不改动角色译名。
- 搜索可匹配原文、译文、参考、角色和编号。类型筛选（全部类型／对话／地点）可与状态筛选、搜索组合使用；筛选只改变显示，不改变导出顺序。
- 输入搜索词或编辑译文时实时刷新筛选；不再符合条件的条目会立即移出当前列表，撤销后会按条件重新显示。“下一未译”“下一提示”按剧本顺序循环定位，必要时清除限制目标显示的筛选。
- 恢复未保存草稿时恢复当前文件格式、自动规范开关和最后活动条目；这不是已保存文件的通用最近打开记录。

## 参考、同步与校验

参考译文支持显示/隐藏及逐条采用，场景文字同样展示参考。参考与载入时译文的文本框按实际行数自动高度，一行文本只占一行，不为来源标签预留空行；来源水印显示在框内右下角，不额外占行高；对照框与输入框使用相同文本边距，完整文本可悬停查看。地点对照最多显示一行，并与输入框居中对齐。采用参考支持一次撤销，显式空白参考保留为空。

载入参考后，参考正文与当前译文中不同的字词会同时以主题色半透明底色和细框标出；一侧缺少文字时，在对应位置显示竖线标记。编辑、采用参考及撤销/重做时实时更新，相同内容不标记。隐藏或移除参考时一并隐藏差异高亮。对话和场景文字均支持，自动折行不算文字差异，显式换行会参与比较；CRLF 与 LF 视为相同换行。高亮不改变编辑、选择、复制或导出内容。

工具栏的“同步相同场景文字”和“同步相同说话人译名”是项目级开关，默认开启，作用于整个剧本（包括被筛选隐藏的条目）。说话人按相同原名同步译名，不修改对话正文。关闭后仅修改当前条目；重新开启只影响后续编辑，不立即覆盖现有译文。恢复草稿会恢复两个开关；同步修改可整体撤销。

校验原因直接显示在译文下方。“最长行加权长度”与“全文字符数”分别标注，不再使用没有说明的分数形式。原文和译文可以显示自动折行，自动折行不写入导出文件。正文最多三行，回车、选择替换和粘贴统一检查，拒绝增加超限换行时显示原因；已有超过三行的内容仍可删减修正。

自动规范包括标点和配置中的用词替换。编辑框聚焦时暂缓改写，离开后应用；关闭“自动规范标点和用词”可保留输入写法。撤销和草稿恢复保留原始文本，不因恢复而重新规范。

## 载入后的修改标记

载入当前译文文件时，记录该次载入的角色译名、对话正文及场景文字快照。后续文字变化用蓝色框标记，参考差异仍用黄色框；重叠时内外框同时显示，编辑区上方提供颜色说明。没有参考文本或关闭参考显示时，蓝色修改标记仍然保留；改回载入内容或撤销到载入内容后自动清除。

保存只更新文件保存状态，不重置载入快照；重新载入/更换当前译文才更新快照，清除译文或更换剧本则清除快照。恢复草稿同时恢复该快照，即使载入后曾保存过，仍可对照最初载入内容。旧草稿没有此字段时，以其最近保存内容作为兼容基准；没有载入译文的新建文档不自动生成载入基准。高亮只表示文本差异，不代表尚未保存，也不影响导出。正文或地点译文相对载入时有变化时，在输入框上方显示“载入时译文”，两边差异均使用蓝框；改回原值时自动隐藏。地点的载入文本保持单行居中，完整内容可悬停查看。

## 保存与快捷键

| 操作 | 快捷键 |
|---|---|
| 保存当前文件 | Ctrl+S |
| 另存为，选择格式及文件名标签 | Ctrl+Shift+S |
| 搜索 | Ctrl+F |
| 下一未译 | Ctrl+Enter |
| 正文换行 | Enter |
| 正文或名称框跳到下一条可见正文 | Tab |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y / Ctrl+Shift+Z |

已有目标时保存保留该文件的 TXT 格式，跳过格式选择；第一次保存与另存为展示格式、预检和完整文件名。预检统计整篇，提示未译回退、显式留空及校验问题；相同目标且摘要未变时快捷保存不重复展示内容预检。覆盖已有文件仍须确认，原生文件选择器已确认当前路径时不重复询问；修改文件名标签后重新确认。

正文翻译框或角色名称翻译框中按 Tab，直接聚焦下一条可见条目的正文翻译框，跳过名称和条目操作；遵循当前筛选顺序，包含场景文字。最后一条保持焦点，不循环到工具栏。Shift+Tab 等组合键以及搜索框、按钮的 Tab 行为保持原有规则。

连续输入按编辑框及短暂停顿合并为撤销操作，粘贴、条目操作、保存和撤销/重做划分边界。保存成功后可主动点击“打开保存位置”，不会自动弹出资源管理器。

退出程序时若有未保存修改，确认弹窗底栏只提供“保存 / 不保存 / 取消”。保存成功才退出；不保存会放弃未保存修改并删除恢复草稿，已保存文件不受影响；取消或关闭弹窗继续编辑，默认选中取消。

## 验证边界

自动测试覆盖状态、导出顺序、显式空白、参考采用、同步、撤销分组及草稿恢复。`Tools/TranslationEditingProbe` 验证 WPF 绑定、明暗主题布局、预检和输入反馈。

真实输入法组合输入、不同屏幕 DPI 和屏幕阅读器仍需人工验证。上述自动检查不替代真实设备验收。

2026-10-30：513 项 Release 回归测试通过；WPF 验证通过深浅主题与 960/1280 宽度下的控件检查。实际窗口已核对深色主题、首次 Ctrl+S 保存的预检及文件名标签、TXT v2 输出、再次 Ctrl+S 的覆盖确认；取消覆盖后样本文件 SHA-256 保持一致。该窗口检查使用隔离的合成样本，不代表长篇真实剧本或所有显示缩放下均已验收。

设置页的“译文换行标记”提供关闭（默认）、`\N`、`↵`。淡色标记仅覆盖正文输入框中的实际换行（CRLF 只显示一次），不写入文本、不参与复制导出，也不影响选区、光标或自动折行；切换即时生效并保存。

翻译列表支持 Ctrl+滚轮及上方 − / + 按钮缩放（100%～200%）；仅正文、原文、名称和对照文本缩放；提示、统计、水印和操作控件保持原大小，角色栏宽度同步变化，正文按剩余宽度重新折行。缩放不修改译文或撤销历史。

按钮或 Ctrl+滚轮缩放时，在列表底部浮显当前百分比；连续缩放刷新显示，停止约 1.2 秒后自动隐藏。浮层不占布局空间、不接收鼠标或键盘焦点。

最长行加权长度与轴机共用 `DialogContentLength`：`.` 为 1/3，其他 ASCII 为 1/2，其余字符为 1；每行去除首尾空白后取最大值，显示最多两位小数。超长检查使用未显示舍入的长度，向上取整后传入现有整数阈值规则，以兼容外部规则配置。
