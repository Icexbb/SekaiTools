## 资源和组件

资源位于 `SekaiToolsGUI/Resources/Design/`，统一使用 `ST.` 前缀，避免覆盖 WPF-UI 的隐式控件样式。

| 文件/组件 | 用途 |
| --- | --- |
| Tokens.xaml | 4/8/12/16/24 DIP 间距、32 DIP 按钮最小高度、8 DIP 面板圆角、Segoe UI Variable/Segoe UI/微软雅黑 UI 字体回退 |
| Palette.Light/Dark.xaml | App、Workspace、Surface、次级表面、悬停、边框、文字、强调和成功/警告/错误语义画刷 |
| Palette.HighContrast.xaml | 使用 Windows 系统 Window/WindowText/Highlight 色动态资源，状态仍需文字与图标表达 |
| Controls.xaml | 显式标题、说明、面板、按钮和可增长的多行编辑器样式；按钮和输入继承 WPF-UI 状态模板 |
| WorkbenchPageHeader | 图标、可折行标题和说明；已接入外壳并跟随实际页面，短窗口隐藏说明 |
| WorkbenchPageToolbar | 基于 WrapPanel 的真实操作容器，保留调用页命名作用域和键盘顺序；UIA 暴露为 ToolBar |
| WorkbenchNotice | 保留 InfoBar 外观，补充 UIA 可读标题/正文和 Polite 状态通知 |

`WorkbenchTheme` 在现有主题设置应用后切换语义字典。当前不改变主题枚举或尚未启用的系统跟随行为。实际下载任务项可通过 `UseWorkbenchTheme` 显式采用语义状态色；默认路径保留原样，Showcase 已启用。

暗色初值沿用原指令的 #191B20 / #252932 / #E6E9EF 等；浅色独立设置。按 sRGB 相对亮度公式计算，以下为文字/状态色与 Surface 的对比度，不代替所有控件、交互状态或系统高对比验收：

| 配色 | 主文字 | 次文字 | 成功 | 错误 |
| --- | --- | --- | --- | --- |
| 浅色 | 15.45:1 | 6.39:1 | 6.61:1 | 6.77:1 |
| 暗色 | 11.97:1 | 6.44:1 | 6.02:1 | 4.62:1 |

现有翻译参考差异、修改差异和识别状态颜色继续保留，后续页面接入时分别审查，不能统一替换为单一强调色。

## Showcase 入口和验证

在显式隔离测试实例或已开启开发者模式的正式实例中，按 **Ctrl+Alt+F12** 打开组件预览。普通模式命令不可执行；不占主导航或设置类别位置。预览通过现有设置模型临时切换主题，关闭时恢复打开前的主题。

预览包含公共页头、编辑器、禁用按钮、可校验输入、选择状态、可访问错误提示，以及实际 `TranslateLineDialog` 和 `DownloadTask` 组件。样例不连接下载处理、不写业务素材，确认按钮仅改变预览反馈。

`UI-DESIGN-001` 经真实快捷键打开窗口，验证三种应用主题下编辑及选择保持、实际翻译行编辑、非法输入禁止确认、错误提示可读、有效输入恢复操作和键盘焦点，保存错误/聚焦截图。另从截图采样根背景，验证亮暗底色实际变化；关闭后通过设置页核对原主题恢复。独立窗口失败时额外采集 ShowcaseFailure 截图与 UIA 树。

## 外壳与紧凑操作

外壳保留自动轴机、脚本翻译、数据下载、视频压制、设置与关于的原顺序。公共页头从实际导航结果取得标题和图标，说明按模块提供；不增加全局任务调度或虚构状态。

工具栏包含展开/收起导航和现有运行日志入口。导航按钮状态绑定实际 IsPaneOpen，避免页面导航自动收起后文案过期。窄窗口沿用 AdaptiveLayout.IsNarrow 将工具栏移到页头下方，短窗口通过同一 IsShort 隐藏说明；没有引入新的断点。运行日志仍使用原 RuntimeLogWindow。

`UI-DESIGN-002` 在960×600窗口验证页头与页面一致、导航开合、日志打开/关闭及返回工作区；`UI-DESIGN-001` 增加800×600预览和受限宽度下真实工具栏折行检查。自有窗口定位同时检查主窗口UIA子树和本进程顶层窗口，避免把已打开的日志窗误判为未打开。
