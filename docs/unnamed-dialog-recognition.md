# 无说话人对话识别

## 行为

原剧本 `WindowDisplayName` 为空或仅含空白时，通过原文正文定位对话，不再要求名字模板命中。翻译中的说话人是否为空不决定识别分支，非空原始名字继续使用名字定位。

正文定位限制在画面下部对话框左侧，优先尝试前三个字符，再尝试两个和一个字符，兼容打字机逐字出现。单字定位最低相关性阈值为 0.90，其他前缀最低为 0.85，且不低于配置中的正文阈值；定位不会使用通用失败回退进一步降低阈值。

首次命中不依赖前一句坐标。之后在上一帧定位附近搜索，支持抖动。正文坐标转换为名字等效锚点后，继续使用原有正文状态机、逐帧记录、消失判断、有限前瞻与断点恢复，不改变保存状态格式。

最终说话人为空时仅输出正文字幕，不生成空的 Character 事件；计算名字宽度时空原始名字返回零，避免创建空文字模板。

## 验证与边界

使用程序生成的字体模板画面验证首句定位、单字短句、多行原文、连续无名对话、抖动位移跟踪、断点恢复、对话区域之外相同文字排除，以及普通和抖动字幕正文输出。完整测试套件与 WPF 构建通过。

尚未用真实无名对话录屏完成验收。搜索区域及正文到锚点的偏移沿用现有对话界面几何约定，实际录屏应重点复核文字位置、首尾时间、背景干扰和缩放差异。连续台词前缀相同或短句在背景中重复时，仍可能存在纯模板匹配的歧义；当前没有引入 OCR 或全文识别。原文正文为空的条目没有可用于识别的文字证据，不自动判为命中。
