# 无剧本时间轴精度修复与回归

日期：2026-11-16。基于 `18c0ef6` 的 [愚人节素材分析](aprilfool-2024-01-timing-analysis.md) 实施修复。基础模式仍只读取视频和已有菜单模板，不读取剧本、翻译或 OCR 模型；剧本仅在独立评估阶段作为时间轴参考。

## 修复内容

1. **区分寻找与保持对话框。** 初次进入仍要求名字栏横线；进入后只要菜单和名字/正文证据持续存在，允许横线暂时消失，解决浅色服装下整段漏失或对白切碎。
2. **在比较正文前补偿整体位移。** 原有 5×5 容差仍保留；重合率不足时，再以 ±8 个归一化像素搜索位移，避免把抖动当作换句。位移搜索有界，不通过无限放大字形膨胀来粘合不同文字。
3. **确认新对白与处理退场分开。** 没有横线时，必须出现明显的正文清空/面积回落和后续稳定证据才能确认下一句。未确认的退场变化只截断旧对白，不生成残影短句；短暂不可见后出现残影时保留首次消失位置，避免结束时间被重新延长。原有最短段时长 0.25 秒未提高。
4. **排除裁切出的背景亮线。** 名字掩码移除接触裁剪边缘的连通域，并要求足够的剩余名字证据。宽屏回归发现的窗框假文字通过这一规则排除，避免无对话框画面继续保持“对白可见”。
5. **保留首行细破折号。** 允许正文首行内高度 2–3 像素的细横线作为起点证据；名字区域和正文其他位置仍使用原有严格过滤。此处不识别文字内容。

没有按角色、剧本编号、素材文件名或固定视频时刻添加例外，也未将 OCR 作为基础模式依赖。
