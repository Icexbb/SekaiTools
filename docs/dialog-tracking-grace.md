# 对话正文短暂失配容错

进入三字正文跟踪后，单帧相关分数下降不再必然结束整句。仅在重新匹配到姓名、且两字正文仍匹配时，进入待确认状态；三字匹配阶段和全局阈值保持不变。无名对话不启用此容错。

待确认窗口为 `ceil(fps × 0.05)` 帧，至少一帧：30 fps 为两帧，60 fps 为三帧。暂存实际姓名坐标；三字匹配恢复时按原帧序提交，否则在窗口耗尽或姓名、两字正文证据消失时丢弃暂存帧，结束于最后可靠帧。视频结束时也不将未确认帧计入字幕。

检查点新增 `Dialog.PendingTrackingFrames`，保存暂存帧号和坐标，状态值 4 表示待确认；恢复后保留原失配窗口起点。旧检查点缺失该字段时按空列表处理。
