# 弹窗用途与尺寸

所有尺寸均为 WPF 逻辑单位（DIP），包括标题、正文和底部按钮。以主窗口标题栏下方的 ContentDialogHost 面板为比例基准；宽度计算 70%，高度随内容自适应，并在窗口调整时同步更新。

| 用途 | 对话框 | 宽度（高度自适应） |
| --- | --- | --- |
| 确认、警告 | 更新、资源失败、任务/草稿恢复、移除任务、清除历史、覆盖、重置设置、未保存修改等动态 ContentDialog | 480 |
| 简单编辑 | 自定义字符、字幕文本快速调整 | 560 |
| 翻译导出 | 翻译保存选项 | 600 |
| 复杂表单 | 添加字幕任务、添加/编辑压制任务、字幕保存选项 | 面板宽 × 70% |
| 列表选择 | 字体选择、历史记录 | 面板宽 × 70% |
| 等待提示 | 下载源刷新、运行环境准备、字幕资源准备 | 480 |

独立的 WPF-UI 覆盖确认和视频处理错误提示宽度固定为 480，高度随内容自适应。系统 MessageBox、文件/文件夹选择框由 Windows 管理；独立错误报告窗口保留原有 860 × 640 和工作区适配，日志与播放窗口为非模态，不采用本规则。

宽度超过面板可用范围时收紧，高度上限为面板可用高度，预留阴影和边距；内容区滚动，底部操作按钮位于正文滚动区之外，不缩小字体。尺寸集中在 `AdaptiveLayout`，自定义对话框通过 `DialogPurpose` 声明分类，动态 ContentDialog 默认采用确认类。

WPF-UI 4.3 的 DialogWidth/DialogHeight 不能单独保证实际显示尺寸，因此固定 DialogRootGrid 内表面容器的宽度，高度保持自动；升级 WPF-UI 后应运行 `TranslationEditingProbe --dialogs` 检查实际宽度、长短内容的高度变化、缩小后边界和放大后恢复。
