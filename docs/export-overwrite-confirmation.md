# 导出覆盖确认与翻译文件名标签

字幕 ASS 和翻译 TXT 在写入前检查目标文件。文件已存在，且本次保存路径窗口未确认覆盖该路径时，显示「覆盖已有文件？」dialog，列出完整路径，提供「覆盖／取消」，默认选中取消。

保存路径窗口显式启用系统覆盖提示；只有窗口成功返回，且确认时文件已存在，才记录该路径已确认覆盖。取消路径选择保留原路径及原确认状态；修改路径会撤销旧路径确认。未存在的文件不弹覆盖 dialog。

翻译保存选项提供「翻译／校对／合意」按钮：替换文件名开头已有的 `【…】` 标签，没有则添加，保留目录、正文文件名及扩展名。点击任何标签都会撤销路径窗口的覆盖确认，包括重复点击当前标签。浏览窗口以当前标签处理后的路径为初始文件名。

取消覆盖时不写入文件、不标记翻译已保存，也不清除识别进度。
