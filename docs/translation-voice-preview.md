# 翻译原始语音预览

行头编号下方的按钮播放原始角色语音；播放期间所有行的语音按钮均禁用，当前按钮沿圆角边框展示播放进度；播放结束或失败后恢复按钮。加载时显示文字和图标，再次点击取消；失败原因显示在提示中，再次点击重试。无语音或缺少剧本标识时隐藏。离开页面或重建翻译项目时停止播放。

参考 PRSK_Editor `Main.pyw::playVoice`，取 `TalkData[index].Voices` 的第一条及其音量，语音资源统一使用 `{ScenarioId}/{VoiceId}.mp3`，不追加 PRSK_Editor 旧实现中的 `_rip` 后缀，路径位于所选下载源的 `sound/scenario/voice/` 下。播放进度每 50 毫秒从媒体实际位置和时长更新，停止或离开页面时清除进度并停止计时器。WPF 使用 MediaPlayer，复用当前网络代理及 Fetcher；不会执行 Qt 的阻塞下载循环。

缓存位于本机 LocalAppData/SekaiTools/VoiceCache，按完整资源 URL 的 SHA-256 隔离数据源和剧本，下载完整后原子替换。媒体解码失败后移除缓存以允许重新下载。播放状态属于行模型；页面维护单一播放器，取消请求并检查请求身份及播放器身份，过期回调不触发播放。

验证：530 项单元测试通过，包括资源路径、二进制缓存、剧本缓存隔离及取消清理；TranslationEditingProbe 验证播放图标、控件复用后点击当前行、无语音隐藏及复用后恢复显示，播放期间全部按钮禁用和停止后恢复、边框进度绑定与绘制，以及既有翻译编辑回归。GUI 构建通过，保留已有 NU1701 警告。真实远程语音和设备输出尚未人工试听。

`partvoice_` 短语音使用 `sound/scenario/part_voice/{角色文件夹}/{VoiceId}.mp3`，不依赖剧本目录。角色 021–026 对应 miku、rin、len、luka、meiko、kaito，默认使用 piapro。MIKU 的 band、idol、street、wonder、night 后缀分别定位 light_sound、idol、street、theme_park、school_refusal 文件夹；文件名保持原样。未知角色或分组报告错误。

## 分层缓存

缓存根目录仍为 LocalAppData/SekaiTools/VoiceCache。`partvoice/` 保存角色短语音，不参与容量淘汰；`voice/` 保存普通剧情语音。普通语音上限为 C 盘总容量的 0.1%，基础范围为 128 MiB–2 GiB，并限制为 C 盘当前剩余空间的 5% 以内；读取容量失败时回退至 128 MiB。每次加载重新计算上限。

加载或命中缓存后，按最后使用时间清理最旧的普通语音。正在加载完成待播放的当前文件、播放中的文件受到保护，因此单个超大文件或正在使用的文件可以暂时超过上限；停止播放后再次清理。`partvoice` 不受此上限约束，解码损坏的文件仍会删除并允许重试。缓存清理失败记入警告，不中断播放。

旧版根目录中的哈希缓存，在对应音频再次使用时迁移至所属分区并复用；未访问的旧文件无法从哈希反推语音类型，保留而不自动删除，不计入新分区上限。
