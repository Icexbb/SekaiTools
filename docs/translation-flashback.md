# 翻译模块闪回标识

载入剧本后，翻译页会自动在来源不同的台词上方显示带历史图标的“疑似闪回”。悬停可查看来源类别、来源标识和原始语音 ID。标识只用于辅助翻译，不写入翻译文件，也不影响字幕。

判定参考 [PRSK_Editor 的 FlashbackAnalyzer](https://github.com/Sutedako/PRSK_Editor/blob/63f524cdc20a401854c62169121ed8c734f67592/src/Flashback.py) 和 Editor.checkFlashback：从语音名称提取来源，每行内去重，以台词中最常见的来源作为当前主要来源，并列时采用最先出现的来源。某行包含其他来源时标记为疑似闪回。通用 partvoice、无语音及无法解析的名称不参与统计或触发标识。

这是语音复用的启发式判断：当闪回占多数时可能反向判断，不能证明画面处于闪回。提示按活动、主线、主线序章、卡面及未知剧情分类，保留原始来源标识；目前未接入参考项目的活动线索目录，不显示活动标题和章节标题。功能离线可用。

自动验证覆盖语音解析、多来源、按行去重、无语音与未知来源、翻译重载、清空、切换剧本和导出不受影响。真实窗口的明暗主题及 125%/150% DPI 显示仍需人工验收。
