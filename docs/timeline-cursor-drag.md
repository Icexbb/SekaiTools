# 时间轴播放光标拖动

按住播放光标的三角头或竖线附近可拖动定位，鼠标指针显示为水平拖动光标。光标拖动优先于字幕起止手柄命中，不修改字幕时间或撤销记录。识别处理中的只读时间轴不允许拖动播放光标。

拖动开始时暂停原预览，移动时同步更新光标、帧号、时间和播放预览画面。解码请求串行处理，只保留最新待定位帧，避免快速移动时堆积过期请求。松开时确保最终位置画面已更新；原先正在播放则从新位置继续，原先停止则保持停止。定位范围限制在视频首尾有效帧。

原播放区间内定位，续播至原区间终点；定位至原区间终点或之后，续播至视频末尾。选择的字幕事件不随播放光标改变。

停止、切换事件或媒体、进入只读状态以及卸载组件时取消未完成定位，防止旧请求覆盖当前预览。

## 验证（2026-10-26）

- WPF GUI 隔离输出构建通过。
- 使用 `event_219_18_1.mp4` 在真实 Dispatcher 下实例化时间轴组件，验证光标命中、连续定位最终位置、画面回调、视频末尾边界、取消、只读限制，以及字幕时间和撤销记录不变。
- 分别使用 WPF 与 OpenCV + NAudio 后端验证播放中拖动及松开后从新位置续播。
- 组件验证入口位于本机忽略目录 `.codex-build/cursor-drag/probe/`，日志为同目录上级的 `legacy-verification.log` 和 `wpf-verification.log`。

组件验证通过不等于实际窗口鼠标操作验收；窗口内拖动手感、125%/150% DPI 和音画主观验收仍需手动确认。
