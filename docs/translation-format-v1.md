# 翻译 TXT 格式 v1（旧 TXT）

v1 指程序保存选项中的“旧 TXT”，支持加载和导出。它是按行顺序对应剧本的纯文本格式，没有版本头、剧本标识或条目编号。新文件默认使用 [TXT v2](translation-format-v2.md)；需要兼容旧工具，或剧本缺少 `ScenarioId` 时可选择旧 TXT。

## 文件与示例

扩展名为 `.txt`，编码为 UTF-8，支持 LF 和 Windows CRLF 换行。每个有效物理行表示一个条目；对话内部的换行写作字面量 `\N`，不能直接拆成两行。

```txt
# 示例：实际条目数量、类型和顺序必须与所载入剧本一致。
初音未来：大家好！
星乃一歌：这是第一行。\N这是第二行。

舞台
教室
初音未来：时间是12:30，标题是：演出开始。
```

这个示例假设剧本依次包含两条对话、一条横幅、一条地点角标及一条对话。空行只用于阅读分组，不表示额外字幕或正文换行。

## 对话与效果

| 条目 | 写法 | 解析方式 |
| --- | --- | --- |
| 对话 | `说话人：正文` | 以第一个全角冒号 `：` 分隔名称和正文，后续冒号属于正文。 |
| 横幅、地点角标 | `效果文本` | 不含全角冒号的有效行统一解析为效果，再由对应剧本位置确定效果类型。 |

半角冒号 `:` 不能分隔说话人。例如 `初音未来:大家好！` 会被当作效果文本；`初音未来：时间是12:30。` 则是合法对话。

说话人名称中不能包含全角冒号；效果文本中也不能直接包含全角冒号，否则会被当作对话。v1 没有用于转义该分隔符的语法，遇到这类内容应使用 v2。

## 正文换行与文本处理

- 大写 `\N` 在对话和效果正文中都会转换为实际换行，导出旧 TXT 时再转换回 `\N`。
- 小写 `\n` 不解释为换行。v1 不提供保留字面量 `\N` 的转义写法，确需该文本时使用 v2。
- 读取时去掉有效行首尾空白，说话人及解码后的各正文行也会去掉首尾空白；行内普通空格保留。导出正文执行相同的逐行空白规范化。
- 对话正文中的每个省略号字符 `…` 在加载时替换为三个英文句点 `...`；效果正文不做这项替换。
- 编辑器可能继续应用 [翻译检查配置](translation-rules.md) 中的自动替换，不能将编辑器行为全部视为文件格式规则。

## 空行与注释

空行及仅含空白的行会忽略。第一列直接以 `#` 开头的整行是注释，不计入条目；不支持行尾注释，正文中的 `#` 保留。

```txt
# 这是注释
初音未来：正文中的 # 不会开始注释。
```

注释判断发生在去除行首空白之前，因此 `  # 注释` **不会被忽略**，会成为一个效果条目。注释请从第一列开始写。v2 的 `\#`、`\@` 转义规则不适用于 v1。

不要添加 `@version:1`。任何行以 `@version`、`@scenario:`、`@dialog:`、`@banner:` 或 `@marker:` 开头时，当前程序都会转交 v2 解析器；错误版本或语法会报错，不会继续按旧 TXT 加载。

## 与剧本匹配

忽略空行和注释后，有效条目必须与剧本中的对话、横幅和地点角标按顺序对应：

1. 对话数量与剧本 `TalkData` 数量一致。
2. 效果数量与加载后的横幅、地点角标数量一致；其他非字幕特效不需要翻译条目。
3. 每个位置的类型一致：剧本需要对话时不能放效果，反之亦然。

不能任意删除、插入或调整条目顺序。相邻的两条对话即使互换也可能通过类型和数量检查，但会对应错误原文；两个效果互换也有同样问题。

v1 不校验 `ScenarioId` 或文件名，仅凭顺序、数量和类型无法识别所有选错剧本的情况。完全为空或只含注释的旧文件不应用翻译，使用原文。

## 空翻译与导出限制

`角色：` 和 `：正文` 在语法上可解析为对话，但 v1 不具备 v2 的“显式空翻译”语义。空正文通常回退到原文，空译名也不能用于强制清空原说话人；空效果行直接被忽略，不能充当一个条目。

因此，若需要故意保留空说话人、空正文或空效果，请使用 v2。将含显式空值的 v2 文档转存旧 TXT，不能保证重新载入后保持相同结果。

旧 TXT 导出按剧本顺序写出，对话使用全角冒号，正文换行编码为 `\N`；对话框关闭位置可能额外输出空行，仅作分组。导出不会写入 `@version`、`@scenario` 或条目标识。

## 与 v2 的区别

| 项目 | v1（旧 TXT） | v2 |
| --- | --- | --- |
| 匹配依据 | 有效行顺序及类型 | `ScenarioId`＋类型＋编号 |
| 对话语法 | `说话人：正文` | `@dialog:001[说话人]`，正文从下一行开始 |
| 正文换行 | 同一物理行内写 `\N` | 直接多行正文，字面量 `\N` 不转换 |
| 空正文 | 无显式空值语义，不能可靠往返 | 支持显式空翻译 |
| 调整条目顺序 | 会改变对应关系 | 可移动完整条目，保留编号 |
| 效果中的全角冒号 | 会误解析为对话 | 作为普通正文保留 |
