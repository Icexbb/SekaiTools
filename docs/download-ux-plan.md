# 小文件资料下载体验优化

场景：单个剧本通常只有 KB 级别，主要等待成本是请求往返和查找操作。沿用现有 WPF-UI、Fluent 图标、主题资源及页面字体；任务进度按数量展示，不做网速、字节进度、剩余时间预测或断点续传。

## 执行与验收范围

1. 网络与写入：连接复用；瞬时错误最多三次请求，404 等确定失败不自动重试；取消传到请求与退避等待；代理切换不打断在途请求；临时文件完整写入后替换目标，失败保留旧文件。用注入 HTTP handler 的确定性测试核对，不把连接复用直接宣称为实测提速。
2. 任务体验：按任务数量展示等待／下载中／成功／失败／已停止；少量并发，停止后保留成功项；失败原因和单项／批量重试；任务固定来源、URL 与保存位置；下载时仍可浏览和加入下一批任务；同名文件明确跳过或替换策略；完成后提供打开目录入口，不主动弹出资源管理器。
3. 查找与界面：各分类提供清晰的关键词搜索、结果数量及重置；保留现有角色、活动、地点和 TalkId 筛选，保留批量加入与去重；展示已加入／已下载状态。队列适应窗口宽度，使用主题语义颜色；检验长标题、空列表、无结果、失败、停止、下载中新增任务及明暗主题。

每部分通过相应测试、格式验证和 Release 构建后独立提交。界面改动需额外核对实际渲染和交互，不用单元测试替代真实窗口证据。保留现有翻译／字幕工作流，不修改用户数据或自动覆盖未经用户选择的文件。

## 当前进度

网络与写入已实现：Fetcher 根据代理设置复用 HttpClient，切换后等待旧请求释放再回收连接；每次请求维持 10 秒超时，临时网络错误、408、429、5xx 最多三次，重试间隔 250／500 ms，可随时取消。原来最多六次的串行重试已移除；保持默认代理行为。下载写入使用同目录唯一临时文件，成功后替换目标，临时文件在结束时清理。已有不传 CancellationToken 的调用保持源代码兼容。

确定性回归覆盖连接复用、404 不重试、临时失败次数上限、请求取消、代理切换时在途请求、失败／取消保留已有文件和成功替换。网络层支持取消尚不等于页面已有停止按钮，后续任务界面仍需接入。


## 队列与状态（第二部分）

已接入最多 3 个请求并发的固定批次；下载期间保留浏览和加入入口，新加入项标记为下一批。停止取消在途请求并保留成功项，未执行项标记停止；主按钮继续未完成任务，另有单项重试和仅重试失败项。错误原因在任务内展示，完整异常进入运行日志。进度按本批任务数量计算，停止项不冒充已处理成功。

每个任务固定来源、URL、保存路径；切换数据源不改变已有任务。可选择本页下载目录，只调整尚未完成项，下载期间不允许变更目录或文件策略。默认跳过同名文件，显式选择替换才允许覆盖；批内相同目标文件名的不同任务会提示冲突。跳过策略即便遇到请求期间新建同名文件也不覆盖。完成后保留页面汇总，不再自动弹出资源管理器；原有打开目录入口保留。退出窗口会取消并等待当前下载请求退出。

视觉沿用 WPF-UI 卡片、Fluent 图标及动态主题语义色。宽页面使用 320 宽队列；窄页面上下排列，底部目录、策略和按钮横向重排，宽任务项将状态与操作放在标题右侧，避免挤掉剧情列表和任务状态。没有使用网速、字节进度或剩余时间。

证据：494 项非界面测试通过，新增并发上限、停止／继续、失败隔离、同名冲突和写入竞态覆盖；Release 构建与范围格式检查通过。`Tools/DownloadUxProbe` 使用真实 WPF 下载页面、可控假请求与离线列表占位，覆盖明暗主题、宽窄及短窗口、六种任务状态和按钮可见性。真实页面按钮流程验证了下载中追加下一批、切源后任务来源及路径不变、停止七项后继续、已成功项不重复请求，最终九项完成。原始截图和报告保留在 `.codex-build/download-ux/queue-layout-8/`。早期探针目录存在主题或尺寸标签问题，最终以该目录为准。

探针不连接真实源站、不打开系统目录选择器，也不代表已完成真实窗口 DPI、键盘导航或完整分类列表验收。第三部分的搜索、结果数、批量选择和列表下载状态仍待推进。
