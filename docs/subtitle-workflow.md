# 字幕任务与复核

新建字幕任务及输出的基本操作见 [使用说明](../README.md#4-添加并识别字幕任务)。任务按队列顺序推进，各任务保留自己的识别结果与检查点。关闭主窗口时停止推进队列，等待当前处理器保存和退出。

## 未完成任务的一次性恢复

首次进入字幕页时，先将上次未完成检查点读入内存并消费磁盘记录，再提示是否恢复。放弃或关闭提示后，下次启动不再提供这些记录；素材缺失的旧记录也会消费，避免反复提示。

队列检查点与同一任务的旧进度副本同时清理。兼容旧版只返回最近一条进度的行为，但消费所有旧版未完成进度文件，防止更旧记录在下次启动出现。已完成历史不受影响。

恢复任务在本次会话内可识别、预览和导出，但不再写入恢复检查点；关闭或移除后无法再次恢复。处理完成仍可写入已完成历史。新建任务正常保存进度，各自拥有一次恢复机会。

## 历史按需加载

历史列表按未完成任务、已完成历史分组。记录显示视频文件名、时间和状态，右侧“加载”按钮加载结果，点击卡片正文不会加载。清除历史仅影响已完成记录。

打开列表只后台扫描 JSON 摘要，跳过逐帧位置、时间码和匹配器状态的对象构造；选择记录后才读取完整状态，后台初始化处理器并恢复结果。结果控件通过有界 Dispatcher 队列分批更新，窗口关闭会等待正在加载的处理器释放。相关实现见 [HistoryCatalog](../SekaiToolsInfrastructure/Persistence/HistoryCatalog.cs)。

2026-10 的历史加载诊断及组件验证已覆盖按需读取、损坏文件跳过、卡片铺满和按钮选择。局部热缓存测量只能说明减少对象分配，不能当作完整恢复耗时保证。

## 时间轴播放光标

拖动三角光标头或竖线附近可定位播放位置，命中优先于字幕起止手柄；不修改字幕时间、所选事件或撤销记录。识别处理中的只读时间轴禁止拖动播放光标。

拖动开始暂停原预览；移动时同步更新光标、帧号、时间和预览画面。定位请求串行执行，仅保留最新待处理位置。松开时更新最终画面；原来播放则从新位置续播，原来停止则保持停止，位置限制在视频首尾有效帧。

在原播放区间内定位，续播至原区间终点；定位至终点或之后，续播至视频末尾。停止、切换事件或媒体、进入只读状态及卸载组件时取消未完成请求，防止旧结果覆盖当前预览。

2026-10-26 已在真实 Dispatcher 和录屏素材上验证 WPF、OpenCV + NAudio 两个后端的定位、边界及续播；实际窗口拖动手感、音画主观效果及 125%/150% DPI 仍需人工验收。

## 部分结果

至少一个识别条目具有非空帧集合时才允许导出。异常或视频结束时已有结果标记为部分完成；未识别项优先使用匹配器记录的具体诊断，无诊断时标为“处理结束前未识别”。部分状态与终止原因保存在历史中，ASS 文件头包含识别统计及未匹配清单，供人工复核。

## 导出覆盖保护

字幕 ASS 与翻译 TXT 写入前检查目标文件。文件已存在、且本次路径选择窗口没有确认覆盖该路径时，显示完整路径及“覆盖／取消”，默认取消。未存在的文件不弹覆盖确认。

系统保存窗口显式启用覆盖提示；窗口成功返回且目标当时已存在，才记录该路径已确认。取消路径选择保留原路径与确认状态；手动改路径、点击翻译文件名标签均撤销旧确认。

取消覆盖不写入文件、不标记翻译已保存，也不清除识别进度。2026-10-26 已有单元及 WPF 组件验证覆盖路径与标签确认失效、覆盖和取消；原生保存窗口的实际操作仍需人工验收。
