# 压制面板验证

运行：

```powershell
dotnet run --project Tools/SuppressionUxProbe -- <GUI DLL 绝对路径> <输出目录> [测试视频路径]
```

加载真实 GUI 组件，渲染 Light/Dark × 1200×850/800×540 DIP 的页面和素材设置，共 8 张 PNG。使用模拟执行进度和三种结束状态，不启动压制进程，不保存用户编码偏好。检查失败状态筛选；提供视频时实际后台读取媒体信息并检查有效帧数。

组件截图用于检查资源、明暗主题、按钮和局部滚动；不替代原生文件选择器、物理拖放、完整 Tab 遍历、高 DPI 或真实编码验收。运行期间不要改变同一个输出目录中的报告。

第三参数使用 `p1` 可运行队列编辑与输出授权边界检查，使用输出目录中的独立测试素材，不启动压制。

面板渲染时还会在宽/窄窗口打开实际执行日志窗口，核对只读文本绑定并关闭。

第三参数 `always` 使用模拟执行器调用真实页面提交路径，验证首项自动执行、串行顺序、编辑保护、成功/取消/失败后继续及选择保持。布局验证现输出 20 张截图，包含额外的等待、成功、失败任务详情。

当前详情已统一：探针不再打开独立日志窗口，改为验证同一详情组件的内嵌参数、只读日志及任务切换绑定，额外检查组件实例保持不变。

第三参数 `overwrite` 使用实际任务对话框和注入的确认结果验证提交时覆盖确认、取消保留表单、重复点击和路径变化的授权边界；不启动编码。
