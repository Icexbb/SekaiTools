# 翻译编辑回归探针

Windows / .NET 10：

```powershell
dotnet run --project Tools/TranslationEditingProbe/TranslationEditingProbe.csproj -p:UseSharedCompilation=false
```

覆盖正文修改、保存基线前后的撤销/重做、角色名及地点联动撤销、新编辑清除重做分支、500 步上限、显式空译文草稿恢复、v2 导出效果编号、损坏草稿容错、清空历史和主要模块恢复（含设置排除及无效值回退）。同时验证真实 WPF 按钮绑定、文本框撤销命令、页面卸载刷新草稿，以及明暗主题下 960/1280 宽度的按钮布局。使用随机临时目录，不读写真实用户的会话文件。

还覆盖保存状态常驻显示、无需悬停的校验说明、未译筛选与导出隔离、无搜索结果提示、保存预检随格式变化、完整文件名标签、聚焦时暂缓规范化、失焦后规范化及超行粘贴说明。草稿兼容性检查包括文件格式、规范化开关、活动条目及旧草稿默认值。纯模型层的撤销分组、参考采用和同步范围等回归位于 `SekaiTools.Tests/TranslationWorkspaceTests.cs`。

运行通过不等同于原生确认弹窗、真实键盘输入法和实际系统 DPI 的人工验收。

参考差异验证覆盖实际载入参考后两侧高亮、相同文本无高亮、地点参考、选择和输入命中、采用参考与撤销、显示开关、条目复用、空白参考的增删标记，以及折行和滚动后的几何位置。生成明暗主题 × 960/1280 宽度的四张截图到 `.codex-build/reference-diff/`，不读取或修改用户的会话与翻译文件。差异算法的中文、Unicode 文本元素、增删、换行与大文本上限回归位于 `SekaiTools.Tests/TextDifferenceTests.cs`。

退出确认验证检查正文仅含提示、底栏只有保存/不保存/取消、默认取消，并通过 UI Automation 实际触发三个原生按钮，核对返回值；生成深浅主题退出弹窗截图到同一验证目录。

载入基准验证覆盖真实 LoadTranslation 路径、无参考时修改标记、两色重叠、隐藏/移除参考后保留蓝色标记、保存不重置快照、磁盘草稿恢复和改回载入文本。生成 `loaded-Dark.png`、`loaded-Light.png`。

Tab 导航验证覆盖正文跳下一条正文、名称跳下一条正文、场景文字、筛选后的顺序、末条不循环和搜索框保持原有行为。

地点参考译文验证其可见正文最多一行、首行按输入框居中、长文本与显式多行不撑高控件，以及完整文本的悬停提示。

载入文本对照验证修改后显示原始译文及两侧蓝框、原文位于输入框上方、地点单行居中，以及改回原值后自动隐藏；双色差异重叠时采用内外框。
