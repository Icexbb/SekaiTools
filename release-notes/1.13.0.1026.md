## 主要更新

### 新增

- 时间轴播放光标支持拖动定位，拖动时实时更新预览画面、帧号和时间；松开后可从新位置续播，不修改字幕起止时间。
- 翻译文件保存选项增加「翻译／校对／合意」标签按钮，一键替换文件名开头的标签，没有标签时自动添加。
- 字幕输出支持分别控制与原文相同、与原文不同的说话人姓名；设置页和单次输出窗口共用输出选项，单次修改不影响全局设置。
- 翻译检查和自动替换规则集中至 `translation-rules.json`，支持配置检查条件、提示内容及替换规则。

### 优化

- 翻译页支持整页拖入剧本重新加载，以及分区拖入参考翻译或当前翻译；文件不匹配、内容为空或格式错误时显示具体原因。
- 未载入剧本时显示居中的载入提示，翻译检查提示适配明暗主题。
- 调整资料下载条目宽度与布局，避免内容超出页面。

### 修复

- 修复抖动台词因正文模板短暂失配而提前结束的问题，新增短暂失配复核与待确认帧保存，断点恢复后保留跟踪状态及实际抖动坐标。
- 修复以无名台词开场时后续字幕定位偏移，以及空白说话人台词的字幕坐标问题。
- 字幕和翻译导出遇到已存在的目标文件时，若未通过保存路径窗口确认覆盖，会再次弹出覆盖确认；点击文件名标签后重新确认覆盖，避免直接覆盖已有内容。
- 修正翻译检查对问号、感叹号和引号内结束标点的判断。
- 修复字幕输出选项复选框的主题样式继承，保持设置页与输出窗口显示一致。

### 工程

- 增加 Apple Silicon macOS 开发客户端和共享 Host 的首个开发切片、构建脚本及协议检查；本次正式发布包仍为 Windows 版本，macOS 客户端尚非正式分发版本。

### 测试

- Release 解决方案构建、393 项自动测试及 GUI 发布通过；已核对主程序版本、Updater、配置文件、libs 整理和 PDB 清理。

- 新增导出覆盖确认、文件名标签、说话人分类输出、翻译检查规则，以及抖动跟踪容错与断点恢复的回归测试。
- 真实抖动素材验证中，目标台词由原先仅识别 7 帧恢复为连续识别 212 帧；在失配帧取消并恢复，最终状态和字幕与连续处理一致。
- 时间轴光标拖动和导出 dialog 已完成隔离 WPF 组件验证；实际窗口鼠标操作、系统原生保存窗口和不同 DPI 的手动验收尚未完成。
