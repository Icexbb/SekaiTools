## 主要更新

### 新增

- 翻译模块增加疑似闪回标识，位于原文下方，显示可解析的来源活动期数、名称及剧情话数；现有元数据不足时依次尝试下载源补齐信息。
- 抖动台词显示与字幕模块一致的抖动行图标，标识颜色适配明暗主题。
- 翻译编辑支持撤销与重做，覆盖正文、角色名及效果文本；联动修改整组撤销，提供工具按钮和快捷键，最多保留 500 步。
- 自动保存未导出的翻译草稿，再次进入翻译模块时可选择重新打开、丢弃或稍后恢复；切换模块保留当前编辑，退出时可保留草稿。
- 启动时恢复上次使用的主要模块，设置与关于不覆盖该记录。

### 优化

- 调整翻译页工具区列宽与间距，未载入剧本时隐藏翻译和参考翻译载入入口，文件信息随可用宽度省略，避免覆盖任务控制。
- 下载卡片纵向填充所在行，同一行保持等高，长短标题混排时更整齐。
- 特殊剧情改为每行一条，避免单条项目撑满页面；新增信息栏显示开始时间、结束时间及本地时区。
- 取消单项加入下载列表时的成功横幅，保留重复任务等必要提示。

### 修复

- 修复正文模板锁定尺度不适合当前台词时持续失配、导致台词过早结束的问题；跟踪失败时有界复核其他允许尺度，高置信确认后更新锁定，不降低配置阈值。
- 加强有限前瞻的正文确认，防止同说话人、共同开头的台词误触发跳句，导致实际出现的台词被标记为缺失。
- 修复正文编辑未完整计入未保存状态的问题，撤销回保存时的内容后自动恢复为已保存状态。
- 修复特殊剧情刷新后下拉选项重复累积及空数据残留的问题。

### 工程

- 整理功能文档、合并重复说明，补充旧版 TXT v1 翻译格式规范。
- 使用 dotnet format 统一 C# 格式，增加仓库格式配置与提交前格式检查规则。

### 测试

- Release 解决方案构建、435 项自动测试及 GUI 发布通过；发布目录的主程序版本、Updater、配置文件、libs 和 PDB 清理已核对。
- 增加闪回来源解析、活动及话数匹配、尺度恢复、同前缀前瞻防误判、真实缺句及检查点恢复的回归覆盖。
- 目标真实录屏从头至 04:43 的复核中，第 45、48 条恢复完整识别区间，第 49、51 条不再被跳过；两个检查点恢复后的状态和 ASS 与连续识别一致。
- 既有抖动样例保持 212 帧；用户已确认本次识别测试通过。
