## 主要更新

### 新增

- 引入 Fluent Workbench，统一脚本翻译、自动轴机、数据下载、视频压制和设置界面的导航、布局与主题。
- 自动轴机任务栏可调宽度，时间轴可折叠和调节高度，为识别结果与时间轴复核留出更多空间。
- 数据下载默认自动选择来源，优先考虑来源权重和响应速度，下载失败时尝试其他来源。仍可在设置中切换到手动选源。
- 活动剧情列表显示活动横幅，角色剧情卡片支持查看特训前后卡图。图片在本地缓存，减少重复下载。

### 优化

- 精简翻译筛选区和条目操作，将编辑选项集中到浮层，保留原文、参考译文及当前编辑的对照。
- 压制任务显示当前阶段、进度和运行指标，高级参数与详情可按需展开。下载队列也可折叠和调节宽度。
- 统一设置卡片、标签和编辑器布局。开发者 HTTP API 面板以掩码显示访问令牌，仍可通过复制按钮获取完整令牌。

### 修复

- 修复字幕和压制等待任务的拖动排序，以及字幕识别期间的时间轴只读状态。没有识别结果的已取消任务无法导出字幕。
- 修复下载列表刷新期间可能把旧搜索结果批量加入队列的问题。
- 明确提示压制输出路径被目录占用的错误。开发者阈值在缺少资源文件时可恢复至内置默认值。

### 测试

- 增加隔离的 FlaUI 桌面回归，覆盖翻译草稿与导出、字幕识别与恢复、视频转码与 ASS 烧录、离线下载及设置重载。发布目录也可单独运行桌面验收。
