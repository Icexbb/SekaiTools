## 主要更新

### 新增

- 增加实验性纯视频对白时间轴识别，无需剧本或 OCR，可手填翻译、预览并导出 ASS；当前主要适用于常规游戏对话框，结果需人工检查，不支持历史记录和断点恢复。
- 增加开发者模式：在设置页连续点击版本号 7 次启用，可调整识别阈值，并通过带令牌认证的本机 HTTP API 查询状态、修改识别设置和切换页面。开发者设置默认折叠。

### 优化

- 更新前先询问是否下载，确认后在后台准备，用户可选择重启时机；更新工作目录迁至用户数据目录，安装或启动失败时尝试回滚，并支持通过更新助手恢复。
- 改善慢速网络下的资源下载等待，增加超时、重试与文件校验；仅在证书过期时允许回退 HTTP。

### 修复

- 改善纯视频时间轴在浅色背景下的漏段及画面抖动导致的误切分，并恢复识别画面预览。
- 更新过程中对被占用文件的操作与哈希读取增加重试，保留失败诊断记录。

### 工程

- 更新助手与解压工具移至 tools/updater/，发布包增加更新文件清单；请完整解压并保留目录结构。
- 增加纯视频识别、时间轴诊断及素材对照分析工具。
