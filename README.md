# Sekai Tools

Sekai Tools 是面向《Project SEKAI》剧情字幕制作的 Windows 桌面工具。它将游戏内录视频、游戏剧本与翻译文本结合，自动识别对话、横幅和地点角标的出现时间，生成带有游戏风格、遮罩和打字机效果的 ASS 字幕。

适用于三周年后剧情界面的录制素材，支持分辨率自适应。自动轴机依赖画面模板与剧本匹配，不会自动听录或翻译；使用前需要准备与视频对应的剧本和翻译。

[下载发布版](https://github.com/Icexbb/SekaiTools/releases/latest) · [版本更新记录](release-notes/) · [反馈问题](https://github.com/Icexbb/SekaiTools/issues)

## 功能

| 页面 | 用途 |
| --- | --- |
| 自动轴机 | 按队列识别剧情时间轴，预览和编辑语句，导出 ASS 字幕，恢复进度或加载历史结果 |
| 脚本翻译 | 载入游戏剧本，编辑角色名、对话和效果文本，载入参考翻译，保存翻译 TXT |
| 数据下载 | 下载主线、活动、特殊、角色剧情与地图对话剧本，按数据源管理缓存 |
| 视频压制 | 将 ASS 字幕压入视频，或仅转码，支持画质、速度和线程设置及任务队列 |
| 设置与关于 | 设置代理、字幕字体、导出样式、识别性能与预览播放方式，查看运行日志 |

## 安装与启动

1. 准备 Windows x64 环境。当前程序目标平台为 Windows 10 版本 2004（Build 19041）及以上。
2. 安装 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)，在下载页选择 **Windows x64** 的桌面运行时。普通 .NET Runtime 不包含 WPF 所需组件。
3. 在 [Releases](https://github.com/Icexbb/SekaiTools/releases) 下载 `SekaiTools-<版本号>.7z`，完整解压到一个可写目录。
4. 运行 `SekaiToolsGUI.exe`。保留同目录的 `libs/`、`runtimes/`、`Updater.exe`、`7zr.exe` 及配置文件，不要只复制主程序 EXE。
5. 首次使用自动轴机或视频压制时，等待程序下载和校验所需资源。网络访问失败时，在“设置与关于”检查代理，再重试。

## 快速开始：从录制视频到字幕

```text
数据下载：取得对应的游戏剧本
    ↓
脚本翻译：填写翻译并保存 TXT
    ↓
自动轴机：加入视频、剧本、翻译，等待识别
    ↓
预览与编辑：复核时间和文本，输出 ASS
    ↓
视频压制：选择视频与 ASS，输出带字幕的 MP4（可选）
```

### 1. 准备素材

每个字幕任务需要以下三个文件：

| 文件 | 格式与要求 |
| --- | --- |
| 视频 | 文件选择器支持 `.mp4`、`.avi`、`.mkv`、`.webm`、`.wmv`；实际能否读取取决于编码。使用固定帧率、保留完整剧情画面的录制素材 |
| 剧本 | 对应剧情的游戏脚本 `.json` 或 `.asset`，可通过“数据下载”取得 |
| 翻译 | UTF-8 编码的 `.txt`，对话和效果条目的数量、类型及顺序必须与剧本对应 |

视频中的剧情顺序应与剧本一致。裁切、跳过剧情、界面布局变化或画面被遮挡都可能造成漏识别；变帧率素材建议先转为固定帧率再制作时间轴。

可以把同一剧情的素材放在同一个目录，并使用相同的文件名主体：

```text
素材/
├── story_001.mp4
├── story_001.json
└── story_001.txt
```

添加字幕任务时勾选“自动选择同名剧本、翻译或视频文件”，选择其中一个文件后，程序会查找同目录的配套文件。加入队列前仍需核对三个路径。

### 2. 下载剧本

1. 打开“数据下载”，选择“数据源”。
2. 切换到主线剧情、活动剧情、特殊剧情、角色剧情或地图对话分类。
3. 点击需要的剧情，将其加入右侧“下载列表”，然后点击“下载”。下载完成后可使用下载的剧本文件。
4. 地图对话可组合地点、角色、ID / TalkId 范围及活动等筛选条件。“全部加入下载列表”只添加当前筛选结果，需要再点击“下载”才会获取文件。

切换数据源会重新加载对应列表，各数据源缓存独立保存。列表过旧时使用“刷新当前列表”；缓存异常时使用“清除缓存”后重新加载。活动追加等带“推断”标识的筛选结果不代表官方首次追加时间，详见[地图对话筛选说明](Docs/action-story-filtering.md)。

### 3. 编辑翻译

1. 打开“脚本翻译”，点击“载入剧本”，选择刚取得的游戏剧本。
2. 根据原文填写角色名称、对话及横幅等效果文本。
3. 已有翻译可通过“载入翻译文件”继续编辑；“载入参考翻译文件”可用于对照。
4. 点击“保存”，将翻译保存为 `.txt`，供自动轴机使用。导出格式默认选择 TXT v2，也可切换为旧 TXT；两种格式导入导出时都会逐行去掉正文首尾空白再合并，并兼容 LF 和 CRLF 换行。

建议使用内嵌编辑器生成翻译文件。TXT v2 使用 `@scenario` 对应剧本内部的 `ScenarioId`，使用 `@dialog:001[说话人]`、`@banner:001` 和 `@marker:005` 标记条目；正文支持多行，可以移动完整条目，但请保留标记及编号。以 `#` 开头的行为注释，特殊正文行首需要转义。完整规则见 [翻译 TXT 格式 v2](Docs/translation-format-v2.md)。

旧 TXT 仍支持加载和导出，手动编辑旧格式时注意：

- 对话使用全角冒号 `：` 分隔角色名与正文，例如 `初音未来：大家好！`。
- 效果文本独占一行，不使用角色名与冒号前缀。
- 空行和以 `#` 开头的注释行会被忽略，不计入翻译条目。
- 不要随意增加、删除或重新排列条目；必须保留剧本需要的对话和效果项。

### 4. 添加并识别字幕任务

1. 打开“自动轴机”，点击左侧“添加”。
2. 在“添加字幕任务”窗口选择视频、剧本和翻译文件，也可将文件拖入素材选择区域。
3. 核对路径后点击“加入队列”。任务按顺序自动处理，等待任务可拖动排序。
4. 点击左侧任务查看它的识别进度、画面预览，以及对话、横幅和标签结果。

需要中断时点击“终止任务”。已识别的部分结果可输出，但应人工复核。新建任务独立保存检查点；下次进入字幕页时仅提供一次恢复机会。关闭恢复提示即放弃恢复，恢复后的任务再次关闭也不再保留恢复记录；需要保留结果时请在本次会话内导出。“历史”用于加载之前完成的识别结果，不会自动重新识别。历史任务仍需要原视频才能进行音视频预览。

关闭主窗口时，程序会停止推进队列并等待当前处理器保存和退出。

### 5. 复核、编辑与输出

1. 在识别结果中检查文本、开始和结束时间，尤其留意未完整识别的任务。
2. 使用语句预览在任务内播放对应片段；编辑按钮可展开并定位时间轴，通过帧画面和播放光标检查边界。
3. 根据需要调整时间、文本与分行。分隔语句时可分别预览前后两段；横幅和标签也支持编辑预览。编辑入口按当前任务状态启用。
   原文为三行时，译文加权总长度超过 37 字才默认启用分行；较短译文仍可手动分行。长度按中文等非 ASCII 字符 1 字、其他 ASCII 字符 1/2 字、英文句点 `.` 1/3 字计算，界面保留一位小数（例如 `......` 显示为 `2.0`）。
4. 点击“输出”，选择保存位置，并按需填写制作人员信息，保存 ASS 字幕。

“设置与关于”中的字体和导出样式会影响生成的字幕。压制或在其他设备播放时，应安装字幕使用的字体，以减少替换字体造成的排版差异。

语句预览默认自动选择播放器：优先使用 WPF 内嵌播放，系统解码失败时回退到 OpenCV + NAudio。可在设置中指定播放方式。预览用于复核片段时间与内容，最终字幕样式应以导出的 ASS 或压制结果为准。

## 视频压制

1. 打开“视频压制”，等待压制资源准备完成，点击“创建任务”。
2. 选择源视频及字幕 `.ass`；字幕可留空，留空时仅转码。
3. 选择输出 `.mp4` 路径，设置画质、编码速度和线程数。
4. 根据需要勾选“添加后自动开始执行任务”，点击“创建任务”；使用页面的“自动执行队列”控制后续任务执行。
5. 等待任务结束，查看输出视频。需要停止时取消对应任务。

画质提供高质量（CRF 18）、均衡（CRF 21）、小体积（CRF 25）和自定义选项。CRF 越低画质通常越高、文件越大；较慢的编码速度通常可提高同等画质下的压缩率。编码线程数 `0` 表示自动。详见[视频压制性能说明](Docs/video-suppression-performance.md)。

## 常见问题

| 问题 | 检查方法 |
| --- | --- |
| 提示缺少 .NET 或无法启动 | 安装 .NET 10 Desktop Runtime x64，确认完整解压且依赖目录仍在主程序旁 |
| 剧本列表或资源下载失败 | 检查网络、当前数据源和代理；必要时清除缓存、刷新列表，并查看运行日志 |
| 无法加入字幕队列 | 视频、剧本和翻译三个文件都需要存在；核对文件路径及格式 |
| 提示翻译与剧本不适用 | 用“脚本翻译”载入对应剧本，检查条目数量、顺序和全角冒号格式 |
| 识别不完整或时间偏移 | 核对视频与剧本是否对应，检查帧率、裁切和跳过剧情情况，预览并修正识别结果 |
| 语句预览无声音或画面异常 | 在设置中切换预览播放方式，检查素材编码；历史任务需保留原视频 |
| 字幕字体或排版与预期不同 | 检查字幕字体是否已安装、导出样式是否正确，并查看最终 ASS 或压制结果 |
| 内存占用较高 | 切换到节省内存模式，适当降低缓存预算或预读帧数上限，减少同时使用的预览 |
| 周期彩色读取选项不可用 | 此项需要通过资格检查的实验运行库，常规发布包可能不可用；保持关闭即可使用普通识别 |

在“设置与关于”展开“运行日志”查看诊断。反馈问题时请附版本号、操作步骤、异常信息及必要的日志；分享日志前检查其中的本地路径等个人信息。

## 从源码构建

在 Windows 上安装 .NET 10 SDK，克隆仓库后在根目录运行：

```powershell
dotnet build SekaiTools.sln -c Release
dotnet test SekaiTools.sln -c Release
dotnet publish SekaiToolsGUI/SekaiToolsGUI.csproj -c Release -o Build/
```

发布命令会构建独立 Updater 并整理依赖目录，输出主程序位于 `Build/SekaiToolsGUI.exe`。

项目结构见[架构说明](ARCHITECTURE.md)，贡献和版本发布遵循[Git 提交与版本发布规范](Docs/git-and-version-conventions.md)。项目内可使用 [`sekai-release`](.agents/skills/sekai-release/SKILL.md) skill 执行版本发布流程。
